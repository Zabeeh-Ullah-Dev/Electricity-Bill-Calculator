# Electricity Bill Calculator

A user-friendly electricity bill calculator that calculates estimated electricity costs based on units consumed, built with HTML, CSS, and JavaScript.

## Rates

- First 100 units: Rs. 10 per unit
- Next 100 units: Rs. 20 per unit
- Remaining units: Rs. 30 per unit

## Run it

Open `index.html` in a browser and enter the units consumed. There is no build step.
